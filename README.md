# 本地 PDF 遮盖工作台

一个完全在本机运行的 PDF 遮盖（redaction）工具：上传一份最多 8 页的 PDF，逐页预览，
在页面上拖动画出不透明黑色遮盖框、单击删除，放大 / 缩小查看后下载遮盖副本。

技术栈：**Python · FastAPI · PyMuPDF · Pillow · 原生 JavaScript（无前端构建）**。

## 一条命令启动

```bash
docker compose up --build
```

启动后在浏览器打开：

> **http://localhost:8000**

端口为 **8000**（宿主机），容器内同样监听 8000。停止服务：`docker compose down`。

不使用 Docker 时也可以本地直接运行（需要 Python 3.11+）：

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

## 使用方法

1. 点击左上角 **“上传 PDF（≤8 页）”**，选择一份未加密的 PDF。
2. 页面逐页显示：
   - **按住拖动**画出黑色遮盖框；
   - **单击已有框**删除它（命中最上层的框），或用每页右上角 **“清空本页框”**；
   - 按 <kbd>Esc</kbd> 取消正在拖的框；
   - 顶部工具栏可以 **放大 / 缩小（50%–200%）/ 重置**；框以 PDF 坐标存储，
     任意缩放、窗口尺寸变化下都对应同一块内容。
3. 预览位图由服务端实时渲染，框内区域在预览中已是纯黑——**所见即所得**。
4. 点击 **“下载遮盖后的 PDF”** 得到 `redacted.pdf`。

## 安全模型（遮盖为什么不可恢复）

下载文件**不是**在原页面上叠一个黑色色块，而是：

1. 把原 PDF 的**每一页重新光栅化为 200 DPI 位图**；
2. 在像素层把遮盖框区域填成纯黑；
3. 用这些位图逐页拼成一份**全新的 PDF**。

因此副本：

- 每页只有一张图片，没有文字层、没有批注 / 表单、没有附件、没有链接；
- 不复制原文档的元数据（标题、作者、Producer 等字段清空，并执行全量垃圾回收）；
- 框内的原始像素根本不存在于副本中，**无法选中、搜索或复制恢复**；
- 保留原 PDF 的**页数、可见尺寸与方向**：新页面使用原页 `page.rect`
  （PyMuPDF 中已经考虑了旋转与 CropBox 裁切），竖页横页、被裁切的页面都能准确覆盖；
- 没有画框的页面同样重新光栅化后进入副本，页数不变。

> 注意：原 PDF 页面之外的信息（如印刷出血、CropBox 外内容）属于“不可见内容”，
> 不会出现在新副本中；这正是重新渲染可见区域的效果。

## 无效 / 加密文件的处理

- 非 PDF、已损坏、**加密 / 带密码**、0 页或**超过 8 页**的文件会被明确拒绝，
  页面顶部显示中文错误原因；
- 上传的文件只有在**全部校验通过后**才替换当前会话，校验失败不会影响正在编辑的文档和框。

文档保存在**服务端内存**中（重启即清空，不落盘）。本工具仅监听本地，默认没有任何鉴权，
请不要把端口暴露到公网。

## HTTP 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| `POST` | `/api/upload` | 上传 PDF（multipart，≤ 50 MiB，≤ 8 页，拒绝加密） |
| `GET` | `/api/document` | 当前会话：页数、每页可见尺寸与遮盖框坐标 |
| `GET` | `/api/page/{index}?zoom=1` | 已应用遮盖的页面 PNG（zoom 0.25–4） |
| `PUT` | `/api/page/{index}/boxes` | 整页替换遮盖框（服务端规范化并裁切到页面内） |
| `POST` | `/api/export` | 下载纯位图版遮盖副本 `redacted.pdf` |
| `GET` | `/healthz` | 健康检查 |

## 限制

- 最多 8 页，上传上限 50 MiB；
- 同一时刻只有一个编辑会话（单用户本地工具），刷新页面会自动恢复当前会话；
- 输出是图片型 PDF，体积通常比原件大，且其中文字无法再被选中搜索；
- 遮盖颜色固定为纯黑不透明。
